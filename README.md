# automation-lab

A monorepo of small, practical automation projects. Each project lives in its own
folder under `projects/` with its own README, setup steps, and tests.

## Projects

| Project | What it does | Status |
|---|---|---|
| [outlook-otp-autofill](projects/outlook-otp-autofill) | Reads one-time passcodes from your Outlook inbox and autofills them in the browser | in progress |

## Layout

```
automation-lab/
  projects/
    <project-name>/
      README.md
      ...
```

## Contributing

Each project is self-contained. Open the project folder and follow its README.
